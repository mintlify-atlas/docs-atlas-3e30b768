These two endpoints provide performance summary data for a promoter: one returns an overall aggregate view (total commissions, signups, purchases) and the other breaks that data down by individual referral links. Both support flexible date filtering via a preset `period` or explicit `start_date` / `end_date` parameters.

## Endpoints

### Promoter Summary

```http
GET /programs/:program_id/promoters/:promoter_id/analytics
```

### Links Summary (Link Analytics)

```http
GET /programs/:program_id/promoters/:promoter_id/link_analytics
```

## Authentication

<Note>
  A valid **Bearer Token** is required for both endpoints. Include it as `Authorization: Bearer <token>`.
</Note>

---

## Promoter Summary

Retrieves aggregated performance metrics for a single promoter within a program. Use this to power a promoter dashboard showing their total earnings and conversion activity.

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program.
</ParamField>

<ParamField path="promoter_id" type="string (uuid)" required>
  Unique identifier of the promoter.
</ParamField>

### Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully got promoter analytics."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="promoter_id" type="string (uuid)">
      Unique identifier for the promoter.
    </ResponseField>
    <ResponseField name="total_signup_commission" type="number">
      Total commission earned from signup conversions.
    </ResponseField>
    <ResponseField name="total_purchase_commission" type="number">
      Total commission earned from purchase conversions.
    </ResponseField>
    <ResponseField name="total_signups" type="number">
      Total number of referred signups.
    </ResponseField>
    <ResponseField name="total_purchases" type="number">
      Total number of referred purchases.
    </ResponseField>
    <ResponseField name="total_revenue" type="number">
      Total revenue attributed to the promoter.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example

```bash
curl -X GET "http://localhost:3001/programs/a1b2c3d4-0000-0000-0000-000000000001/promoters/p5e6f7g8-0000-0000-0000-000000000002/analytics" \
  -H "Authorization: Bearer $TOKEN"
```

## Link Analytics

Retrieves a paginated breakdown of performance metrics grouped by each individual referral link belonging to the promoter. Use this to identify which links are driving the most conversions.

### Path Parameters

<ParamField path="program_id" type="string (uuid)" required>
  Unique identifier of the program.
</ParamField>

<ParamField path="promoter_id" type="string (uuid)" required>
  Unique identifier of the promoter.
</ParamField>

### Query Parameters

<ParamField query="sort_by" type="string">
  Field to sort link analytics by. Accepted values:

  - `createdAt` — Sort by the date the link was created. *(default)*
  - `commission` — Sort by total commission generated by the link.
</ParamField>

<ParamField query="sort_order" type="string">
  Sort direction. Accepted values: `ASC` | `DESC`. Defaults to `DESC` (newest first).
</ParamField>

<ParamField query="skip" type="number">
  Number of records to skip for pagination. Defaults to `0`.
</ParamField>

<ParamField query="take" type="number">
  Maximum number of records to return per page. Defaults to `10`.
</ParamField>

### Response

A successful request returns HTTP `200 OK`.

<ResponseField name="message" type="string">
  `"Successfully got promoter link analytics."`
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result">
    <ResponseField name="data" type="array">
      Array of per-link analytics records.
      <Expandable title="link analytics entry">
        <ResponseField name="link_id" type="string (uuid)">
          Unique identifier for the referral link.
        </ResponseField>
        <ResponseField name="url" type="string">
          The referral link URL.
        </ResponseField>
        <ResponseField name="signups" type="number">
          Number of signups driven by this link.
        </ResponseField>
        <ResponseField name="purchases" type="number">
          Number of purchases driven by this link.
        </ResponseField>
        <ResponseField name="commission" type="number">
          Total commission earned through this link.
        </ResponseField>
        <ResponseField name="created_at" type="string (ISO 8601)">
          Timestamp when the link was created.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="count" type="number">
      Total number of link analytics records for this promoter.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example

```bash
curl -X GET "http://localhost:3001/programs/a1b2c3d4-0000-0000-0000-000000000001/promoters/p5e6f7g8-0000-0000-0000-000000000002/link_analytics?sort_by=commission&sort_order=DESC&skip=0&take=10" \
  -H "Authorization: Bearer $TOKEN"
```

## Status Codes

| Code | Meaning |
|---|---|
| `200 OK` | Summary or analytics data retrieved successfully. |
| `400 Bad Request` | Invalid path or query parameters. |
| `401 Unauthorized` | Missing or invalid Bearer Token. |
| `403 Forbidden` | Authenticated member lacks access to this promoter's data. |
| `404 Not Found` | Promoter or program not found. |
